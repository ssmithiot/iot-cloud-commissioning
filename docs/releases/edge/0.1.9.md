## BACnet Route Policy

Existing configured gateways preserve current BACnet settings. The updater does not rewrite an existing `BACNET_IP_PORT`, `BACNET_IP_PORTS`, `BACNET_PORT_MODE`, or `BACNET_EDGE_PROGRAM_PORTS` value.

Fresh or genuinely unconfigured installs receive external BACnet router defaults:

- external router mode
- UDP `47814`
- internal Edge BACnet router disabled by default router configuration

## Rollout Boundary

This release record prepares the Legacy Updater package and release branch only. It does not authorize retagging, merge to `main`, or fleet rollout.

## Validation and rollback

Validation is run from clean release workspaces before retagging. Required
checks include UI compile/template/safe tests, agent route/version tests,
Legacy Updater package inventory tests, and route-preservation fixtures for
existing `47809`, existing `47814`, Edge-router-enabled, and unconfigured
startup scripts.

Rollback remains the existing Legacy Updater code-only checkpoint restore. It
preserves `data/`, `.env`, `start.sh`, credentials, gateway identity, saved
devices/templates, programs, trends, timed overrides, authentication, cloud
identity, and BACnet route settings.
